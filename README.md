🎉 Promoção Madeira e Cia Ltda.
Este projeto foi desenvolvido para a promoção de aniversário da empresa Madeira e Cia Ltda., aplicando descontos diferentes conforme a forma de pagamento escolhida pelo cliente.

📂 Estrutura do Projeto
madeira.html → Página principal com o formulário para coleta dos dados do cliente.

estilo.css → Arquivo de estilos para personalizar o layout do formulário.

processa.php → Script PHP responsável por processar os dados, calcular os descontos e exibir a mensagem final ao cliente.

🛠️ Funcionalidades
Captura do nome do cliente, valor da compra e forma de pagamento.

Aplicação correta dos descontos:

Depósito → 10%

Boleto → 8%

Cartão de crédito → sem desconto

Exibição da mensagem personalizada com:

Valor original da compra

Valor do desconto aplicado

Valor final após desconto

Valores formatados com duas casas decimais.

🚀 Como Executar
Clone este repositório no seu ambiente local.

Certifique-se de ter um servidor PHP (ex: XAMPP, WAMP ou similar).

Coloque os arquivos na pasta htdocs (ou equivalente).

Acesse http://localhost/madeira.html no navegador.

Preencha o formulário e teste cada forma de pagamento.

✅ Testes Realizados
Depósito → desconto de 10% aplicado corretamente.

Boleto → desconto de 8% aplicado corretamente.

Cartão de crédito → sem desconto, valor final igual ao original.

💡 Observação
O projeto foi estruturado separando HTML, CSS e PHP, seguindo boas práticas de organização e manutenção de código.
